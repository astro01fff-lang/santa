# Автотесты игры «Спасти Рождество»

Папка `tests/` нужна только для проверки игры. На сайт она не влияет: игра (`index.html`, `host.html`) из неё ничего не подключает.

## Что нужно один раз

- Node.js 18+ и Playwright с Chromium: `npm i -g playwright && npx playwright install chromium`
- Зависимости брокера: `cd tests && npm i` (aedes и websocket-stream)

## Запуск

Из корня репозитория:

```bash
node tests/qa.js
```
Полный прогон: ведущая и 4 команды по 2 виртуальных игрока проходят игру от пролога до победы над Королевой, все команды одновременно.

```bash
node tests/qa.js --chaos --seed 42
```
Режим хаоса: у всех игроков случайное поведение. С тем же `--seed` прогон повторяется так же.

```bash
node tests/regress.js
```
Регрессия ранее найденных багов (кукольный домик, баннер «Уровень пройден» у всех, финал без щита, звук, пропадание связи, уход лидера, конюшня).

Полезные ключи `qa.js`: `--teams 2`, `--levels stable,kitchen` (только эти уровни; команду на первый из них переводит ведущая), `--headed` (видно окна браузера). С переменной `QA_VERBOSE=1` в консоль пишутся последние действия игроков для каждой проблемы.

Скрипты сами поднимают тестовый веб-сервер (`serve.js`, порт 8765) и локальный MQTT-брокер (`broker.js`, порт 9001), если они ещё не запущены. Тестовый сервер на лету добавляет в страницу крючок `window.__EV` для ботов. Сам файл игры не меняется.

## Профили игроков (основной прогон)

| Команда | Игрок 1 | Игрок 2 |
|---|---|---|
| 1 | последовательный | последовательный |
| 2 | активный: одновременные клики, быстрые щелчки по сцене | исследователь: нажимает всё подряд |
| 3 | невнимательный: обновляет страницу, уходит в соседние комнаты, жмёт Escape | последовательный |
| 4 | нестабильная связь: пропадает сеть на 2–8 с | активный |

Каждый шаг делает случайный (по сиду) игрок команды, поэтому находит вещь один, а применяет другой.

## Что получается

`tests/out/<прогон>/report.md`: команды, время по уровням, найденные проблемы (серьёзность, команда, игрок, комната, последние действия, ошибки консоли и сети, скриншоты, сид) и все проваленные проверки. Рядом лежат `report.json` и папка `shots/`. Папка `out/` в git не попадает.

## Ограничения

- Брокер локальный: публичный брокер EMQX, который используется в игре, отсюда не проверяется.
- Пропадание связи имитируется режимом «офлайн» в браузере.
- Боты знают ответы загадок из кода. Насколько загадки понятны людям, тесты не оценивают.
- Видео не пишется, только скриншоты.
